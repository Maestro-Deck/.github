# Maestro Deck

We help teams ship software they can trust.

Maestro Deck is a young company building tools and services for software quality: making testing simpler, more accessible and more reliable, from the first prototype to production.

## Our mission

Quality shouldn't be a luxury reserved for large teams. We build the tools and practices that let any team test properly and release with confidence.

## What we do

- **Products**: a desktop client and a cloud platform for running and monitoring tests, plus a device farm for testing on real hardware.
- **Engineering**: we build in the open when we can, and we care about clean code, solid reviews and security.
- **Learning**: our team includes students, and we treat every project as a place to learn how professional software gets made.
