# Security Policy

## Reporting a vulnerability

If you think you've found a security vulnerability in a Maestro Deck project, **do not open a public issue**.

Use GitHub's private reporting: in the relevant repository, go to the **Security** tab → **Report a vulnerability**.

If that option isn't available, email: **contact@maestrodeck.cloud**

Please include:
- the affected repository and version;
- steps to reproduce the problem;
- the impact you think it has;
- if possible, a suggested fix.

## What to expect

- An acknowledgment within a few days.
- A reply on severity and next steps.
- A fix as quickly as possible depending on severity, and credit if you want it.

## Please

- don't access or modify other users' data;
- don't degrade the service (no denial of service);
- give us a reasonable amount of time to fix the issue before any public disclosure.
